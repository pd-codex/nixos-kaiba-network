02 / Guarantees

Specific controls, not security theater.

A

Identity-bound updates

The client certificate determines the device and DNS owner. Request bodies cannot choose a hostname, zone, TTL, or record type.

B

Durable intent, observable convergence

Accepted, origin-applied, and publicly-observed remain distinct states. A 202 means intent is durable—not that DNS has already converged.

C

A constrained DNS writer

Only the publisher owns the TSIG update credential. P0 is writable; P1 and public secondaries remain authoritative-only and non-recursive.

D

Evidence you can inspect

The reproducible topology records assertions, answers, serials, snapshots, and normalized evidence—even when a functional assertion fails.

! PILOT BOUNDARY

Built to make the production boundary visible.

This is an executable pilot, not a production deployment. It uses kaiba.test, a simulated parent authority, test-only credentials, and public secondary emulators. It does not contact Namecheap or change kaiba.network.

Real provider integration and SLAs, Internet and NAT behavior, ACME, DNSSEC, automatic origin promotion and fencing, redundant controllers, fleet-scale operation, production secrets, deployment, and monitoring remain outside the exercised scope.
